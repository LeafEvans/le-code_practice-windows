# Expense Tracker · RN + HarmonyOS Test Project

**Date**: 2026-07-08
**Status**: Approved
**Scope**: Projects RN test_07_08

## Overview

A local-first expense tracking app built with Expo SDK 55 + React Native 0.82, with HarmonyOS deployment capability via expo-harmony-toolkit. Serves as a testbed to validate RN → HarmonyOS workflow.

**No backend, no API, no login — pure local app.**

## Tech Stack

| Layer | Choice | HarmonyOS Verified |
|---|---|---|
| Framework | Expo SDK 55 + RN 0.82 | ✅ expo55-rnoh082-ui-stack |

## Pages

### 1. Dashboard (`app/index.tsx`)
- Three summary cards: income, expense, balance (this month)
- Expense category pie chart (SVG)
- Floating "Add Record" button (FAB)

### 2. Records List (`app/records.tsx`)
- Month selector (swipe or dropdown)
- List of records: color-coded (green income, red expense)
- Swipe left to delete
- Tap to edit (future)

### 3. Statistics (`app/stats.tsx`)
- Monthly income vs expense bar chart (SVG)
- Top expense categories ranking

### 4. Add Record (`app/add.tsx` — modal)
- Amount input (numeric keyboard)
- Type toggle: income / expense
- Category picker (icon grid)
- Date picker
- Note text input
- Save button

## Data Model

```ts
interface Record {
  id: string;        // UUID
  type: 'income' | 'expense';
  amount: number;    // positive number
  category: string;  // category key
  date: string;      // YYYY-MM-DD
  note: string;
}
```

## Data Flow

```
AddRecord → AsyncStorage (JSON key: "records")
                ↓
Dashboard ← records[] → calculate monthly totals, category sums
Records  ← records[] → list filtered by month
Stats    ← records[] → monthly trends, category ranking
```

## HarmonyOS Integration

Steps (not all executed now, documented for future):
1. `pnpm add expo-harmony-toolkit` — install toolkit
2. `pnpm expo-harmony-toolkit doctor` — environment check
3. `pnpm expo-harmony-toolkit init` — generate harmony/ native project
4. `pnpm expo-harmony-toolkit bundle` — bundle JS for HarmonyOS
5. Open DevEco Studio → open harmony/ → build HAP
